# **App Name**: TourVista Admin

## Core Features:

- Admin Authentication: Secure the dashboard using Supabase Authentication with email/password. Only authenticated users can access the dashboard.
- Tour Package Management: CRUD operations for tour packages including rich text editing for descriptions, inclusion/exclusion lists, and policies.
- Trip Day Management: Manage trip days with activity timelines, location selection from a map, and linking to tour packages.
- Trip Location Management: Create and manage trip locations with map integration for coordinate selection and multi-image upload.
- Booking Management: View and manage bookings, including status updates, payment information, and customer details.
- Review Management: Moderate and respond to customer reviews with star ratings.
- AI-Powered Tour Suggestion: Suggest tour package types to operators based on existing itinerary activities by evaluating existing trip activity descriptions with an AI tool that analyzes user data.

## Style Guidelines:

- Primary color: Deep Indigo (#4F46E5) to convey trust and sophistication.
- Background color: Very light gray (#F9FAFB), subtly tinted toward indigo to maintain brand consonance and support the content.
- Accent color: Sky Blue (#38BDF8) for interactive elements and highlights, providing a refreshing contrast.
- Body and headline font: 'Inter' sans-serif for a modern and neutral look.
- Use simple, line-based icons from the Remix Icon set to maintain a clean and professional aesthetic.
- Consistent layout with collapsible side navigation and top bar for all pages. Use ShadCN UI components to maintain visual consistency.
- Subtle transitions and animations for UI elements to provide a smooth and engaging user experience.
